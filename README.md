# 🥠 흔들어! 포춘쿠키

핸드폰을 흔들면 랜덤 운세/멘트를 푸쉬 알람으로 보내주는 PWA 웹앱.

## 사용 방법

1. 모바일 브라우저(Safari/Chrome)로 `index.html`을 엽니다.
2. **알림 허용하고 시작하기** 버튼을 눌러 권한을 부여합니다.
   - iOS는 모션 센서 권한도 함께 요청됩니다.
3. 핸드폰을 흔들면 🥠 포춘쿠키가 깨지며 운세 알림이 도착합니다.
4. 홈 화면에 추가(PWA 설치)하면 앱처럼 사용할 수 있습니다.

## 배포

정적 파일이므로 GitHub Pages / Netlify / Vercel 등에 그대로 올리면 됩니다.
**HTTPS 필수** (모션 센서 · 알림 API 요구사항).

## 파일 구조

- `index.html` — 메인 앱 (흔들기 감지 + 알림)
- `manifest.json` — PWA 매니페스트
- `sw.js` — 오프라인 캐시용 서비스 워커
- `icon-192.png`, `icon-512.png` — 앱 아이콘
